A row of tabs, a note when you need it

Move the cursor to the right edge. The tabs fan out; touch one for a quick look, click it to write.

What it does

Small, quiet and yours. Nothing to sign up for.

  • A deck on the screen edge

    Notes are tabs on the right edge. A quick look does not take focus from the app you are in.

  • Anchored or floating

    Float Note (⌥⌘P) lifts a note off the edge, resizable, and it remembers its place.

  • Markdown as you type

    Bold, links, headings, lists, checklists, quotes, code, tables, all with shortcuts.

  • Colors and tags

    Five paper colors and #tags with suggestions. Search covers title, tags and text.

  • Daily notes

    Today’s Daily is one shortcut away (⌥⌘Y). The last two days stay on the deck; older ones go to Daily in All Notes.

  • Pin, keep, archive by time

    Pin up to five notes to the center. Notes unopened for 7, 14 or 30 days move to the Archive, never deleted.

  • Sync through a folder

    Optional plain-text files in a folder you pick, such as iCloud Drive. No server of ours in between.

  • Import and export

    Markdown, plain text, or a KeepNote archive that keeps colors, states and dates.

  • Quiet by design

    In the menu bar, and in the Dock only while one of its windows is open.

Install in three steps

Download the disk image, then:

  1. Drag it to Applications

    Open KeepNote.dmg and drag KeepNote onto the Applications shortcut.

  2. Open it

    macOS says it could not verify KeepNote. Click Done (or OK). This is expected.

  3. Allow it once

    System Settings → Privacy & Security → Security → Open Anyway. It will not ask again. (On macOS 13 and 14, Control-click the app and choose Open also works.)

Why does macOS show a warning?

KeepNote is not notarized by Apple. Notarization needs a paid Apple Developer membership (US$ 99 a year), and KeepNote is a free, open-source project, so it ships without it for now. macOS shows this warning for every app that has not been through that process. It says Apple has not checked the app, not that something is wrong with it. These are the four things you can check for yourself instead:

  1. You can read it, and build it.All of the source code is in the repository, with no third-party libraries. ./Scripts/build.sh builds the same app from it.
  2. It cannot use the network.KeepNote runs in the macOS sandbox without the network entitlements, so the system refuses any connection it tried to make. See for yourself: codesign -d --entitlements - /Applications/KeepNote.app lists no network access.
  3. It only reaches what you give it.Outside its own container, the sandbox lets KeepNote open only the folders and files you pick, for sync, import and export. The text of your notes is encrypted on disk with a key that stays in this Mac’s Keychain.
  4. You can check the download.Each release carries a KeepNote.dmg.sha256 file. shasum -a 256 KeepNote.dmg must print the same value.
