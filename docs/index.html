A row of tabs, a note when you need it

Move the cursor to the screen edge, right or left as you choose. The tabs fan out; touch one for a quick look, click it to write.

What it does

Small, quiet and yours. Nothing to sign up for.

  • A deck on the screen edge

    Notes are tabs on the right edge, or on the left one: everything mirrors to come out towards the middle. A quick look does not take focus from the app you are in.

  • Anchored or floating

    Float Note (⌥⌘P) lifts a note off the edge, resizable, and it remembers its place.

  • Markdown as you type

    Bold, links, headings, lists, checklists, quotes, code, tables, all with shortcuts.

  • Colors and tags

    Five paper colors and #tags with suggestions. Search covers title, tags and text.

  • Edit in All Notes

    The selected note opens in All Notes’ pane with everything a note has — shortcuts, Tools, find, colours, tags — and saves on its own. Open in a window too, it is one note: what you type shows in both at once. New Note makes it right there; the list sorts by Edited, Created or Title; ↑ ↓, Return and Esc move between list and note.

  • Daily notes

    Today’s Daily is one shortcut away (⌥⌘Y). The last two days stay on the deck; older ones go to Daily in All Notes. You can set a template for new daily notes, and yesterday’s unticked tasks can come along: offered at the top of the new daily, or brought in at once.

  • Pin, keep, archive by time

    Pin to Center holds up to five notes in the middle of the deck, always whole. Keep on Deck exempts a note from archiving. Notes you have not opened for 7, 14 or 30 days (you choose; 14 by default) move to the Archive on their own, never deleted; in the last two days a clock appears on the tab.

  • Daily backups

    Each day a copy of the database, encrypted like the original, beside it on this Mac; the seven most recent are kept, and one is made before an update. Settings → General → Backups has Back Up Now and Restore….

  • Images and files

    Drag a picture in, paste a screenshot or use Insert Image…: it sits in the text at the note's width. Other files are cards with their icon, name and size; Space opens Quick Look. Up to 25 MB each, encrypted like the text, and an image's description is what VoiceOver reads.

  • Links and mentions

    A click opens a link. Paste an address and keep it as a mention: the site's initial and a title read from the address itself. Nothing is fetched.

  • Sync through a folder

    Optional plain-text files in a folder you pick, such as iCloud Drive, attachments as plain copies beside them. No server of ours in between.

  • Import and export

    Markdown, plain text, or a KeepNote archive that keeps colors, states and dates; images and files go along.

  • Quiet, and your shortcuts

    In the menu bar, and in the Dock only while one of its windows is open. Every global and in-note shortcut can be recorded again in Settings; conflicts are caught, and Restore Defaults puts KeepNote’s back.

Install in three steps

Download the disk image, then:

  1. Drag it to Applications

    Open KeepNote.dmg and drag KeepNote onto the Applications shortcut.

  2. Open it

    macOS says it could not verify KeepNote. Click Done (or OK). This is expected.

  3. Allow it once

    System Settings → Privacy & Security → Security → Open Anyway. It will not ask again. (On macOS 13 and 14, Control-click the app and choose Open also works.)

KeepNote does not check for updates by itself, because it has no network access. New versions are published here on the site and on the releases page. In the app, Settings → About → Check for Updates… opens this page.

Why does macOS show a warning?

KeepNote is not notarized by Apple. Notarization needs a paid Apple Developer membership (US$ 99 a year), and KeepNote is a free, open-source project, so it ships without it for now. macOS shows this warning for every app that has not been through that process. It says Apple has not checked the app, not that something is wrong with it. These are the four things you can check for yourself instead:

  1. You can read it, and build it. All of the source code is in the repository, with no third-party libraries. ./Scripts/build.sh builds the same app from it.
  2. It cannot use the network. KeepNote runs in the macOS sandbox without the network entitlements, so the system refuses any connection it tried to make. See for yourself: codesign -d --entitlements - /Applications/KeepNote.app lists no network access.
  3. It only reaches what you give it. Outside its own container, the sandbox lets KeepNote open only the folders and files you pick, for sync, import and export. The text of your notes is encrypted on disk with a key that stays in this Mac’s Keychain.
  4. You can check the download. Each release carries a KeepNote.dmg.sha256 file. shasum -a 256 KeepNote.dmg must print the same value.

Accessibility

  1. VoiceOver. The stripe is a button that opens the deck; each tab reads its note’s title, colour and states (pinned, kept, floating, daily, archives soon) in the order drawn. Icon-only buttons have labels, checklist items are checkboxes, and KeepNote announces notes made, archived, deleted (with Undo one step away), pinned or returned, tasks brought and notes archived by time.
  2. Keyboard. Focus Deck (⌃⌥⌘D, changeable) gives the deck the keyboard: arrows or Tab between tabs, Space to peek, Return to open, Esc to leave. ⌘↩ ticks a task. In All Notes, ↑ and ↓ move through the list, Return goes into the note, Esc comes back. With Keyboard navigation on, Tab reaches every button, with a focus ring that shows on every paper colour.
  3. Display. Increase contrast, Reduce transparency and Reduce motion are followed. Settings → General → Text size goes from Small to Extra Large for notes, the peek and All Notes.
  4. Colour. Text is at least 4.5:1 on every paper, with and without Increase contrast, and no state is shown by colour alone.

Uninstall

Quit KeepNote first (menu bar icon → Quit KeepNote). If Launch at login is on, turn it off in Settings → General before you delete the app. Then remove each of these:

  1. The app. /Applications/KeepNote.app. Move it to the Trash.
  2. The database, your notes. ~/Library/Containers/com.keepnote.KeepNote/Data/Library/Application Support/KeepNote/notes.sqlite, with notes.sqlite-wal and notes.sqlite-shm beside it. Delete the whole container, ~/Library/Containers/com.keepnote.KeepNote: in the Finder choose Go → Go to Folder…, type ~/Library/Containers, and move the folder named KeepNote to the Trash.
  3. The backups. ~/Library/Containers/com.keepnote.KeepNote/Data/Library/Application Support/KeepNote/Backups, up to seven copies of the database. They go with the container; to remove only them, move the Backups folder to the Trash.
  4. The preferences. ~/Library/Containers/com.keepnote.KeepNote/Data/Library/Preferences/com.keepnote.KeepNote.plist. It goes with the container.
  5. The encryption key. A password item in the login keychain, service com.keepnote.KeepNote.bodykey, account default. In Keychain Access, search for it and delete it, or run security delete-generic-password -s com.keepnote.KeepNote.bodykey in Terminal.
  6. The login item. KeepNote itself, registered with macOS while Launch at login is on. Turn that off before deleting the app. If the app is already gone: System Settings → General → Login Items (Login Items & Extensions on macOS 15 and later), select KeepNote under Open at Login and click −.

The key only decrypts that database and its backups, so remove them together. Once the container is gone your notes and their backups are gone with it: export them first (Settings → About → Export All Notes…) if you want to keep them.

Your sync folder is yours. KeepNote never deletes it, and uninstalling leaves it, its .hmnote and .hmtemplate files and its Attachments folder exactly where they are. Delete it yourself if you no longer want it.
